# iBEC Submission Template Package

Primary language: English. Chinese notes may be added only where necessary.

Use the Team ID assigned by the organizing committee in submitted file names and on the title page of the project report. A transparent-background iBEC logo file is also included for official competition materials.

## 01_Project_Report

- `Word/01_Project_Report_Template.docx`: editable Word template.
- `LaTeX/01_Project_Report_Template.tex`: LaTeX source matching the Word template content.
- `PDF/01_Project_Report_Template.pdf`: compiled PDF preview from the LaTeX source.

## 02_Technical_Abstract

- `PPT/02_Technical_Abstract_Template.pptx`: editable 16:9 PowerPoint template, controlled within 10 slides.
- `PDF/02_Technical_Abstract_Template.pdf`: PDF generated from the PPT slide previews.

No LaTeX version is included for the technical abstract.

## 03_Supplementary_Materials

- `Word/03_Supplementary_Materials_Template.docx`: editable Word template.
- `LaTeX/03_Supplementary_Materials_Template.tex`: LaTeX source matching the Word template content.
- `PDF/03_Supplementary_Materials_Template.pdf`: compiled PDF preview from the LaTeX source.
- `README_Template/03_Supplementary_README_Template.md`: optional README template for code, data, results, demo links, and reproducibility notes.
