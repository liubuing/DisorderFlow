## 1. 任务定义（与 C1 的本质区别）

C1 测的是"native vs 竞争者"（答案由沉积坐标决定）。Phase D 测的是
**binder vs non-binder**：给定骨架-表位上下文，判别一条 CDR 序列（或一个
骨架-表位对）是否结合。答案由实验结合测量决定，不由结构存在性决定。
这需要两类此前从未入仓的数据：经验证的结合体（binder）与经验证的
非结合体（non-binder）。

## 3. 终点与门（冻结时按本节执行）

- 主终点：家族级 binder-vs-nonbinder AUC；家族一致性符号检验（α=0.05 单侧）。
- 功效表（已冻结：`results/flex_phase_d_v1/power_table.json`）：24 家族时
  检出"75% 家族阳性"功效 0.77；30 家族 0.89；**可行性门定在 ≥24（目标 30）
  由此而来**。当前 8–9 家族在同类效应下功效 ~0.24，不设门、直接判负。
- 强制基线（M8）：组成模型（与 non-binder 组成匹配后仍有意义）、
  ProteinMPNN NLL、以及 C1 裁判（flex_ecls_marginal）作为被试者之一——
  Phase D 同时回答"ECLS 信息里有没有超越组成的结合信息"。
- 门：≥70% 家族 AUC > 0.5 且家族聚类 CI 排除 0.5，且对两条强制基线的
  配对优势 ≥70% 家族。
- 失败后果：ECLS 线终结于边界研究（手稿已备）；Phase D 判别器线另议。

## 3.5 试点结论与 v3 组装单位（2026-10-31 冻结）

三轮试点把可行性从"数量富余"推进到"单位正确"：

- **v1**（`pilot_summary.json`）：按记录量选的前 8 抗原全是冠状病毒复制酶
  重叠窗口扫描——精确组成匹配把 binder 配到自己的移位窗口上，对照被位置混淆。
  **体量 ≠ 家族质量**。
- **v2**（`pilot_v2_summary.json`）：Hamming 去混淆是错误的工具（移位窗口的
  Hamming 距离本来就高；混淆在源蛋白位置重叠），产率不动。正确的解药是
  `starting/ending_position` 位置约束。
- **受体级单位证伪**：IEDB B-cell 里受体注释记录 4,734 条，阳性 4,160 vs
  阴性仅 12——"同一抗体的双标签"在公共数据里不存在。
- **v3 单位（冻结：`feasibility_addendum_v3.json`）**：用 PDB 锚定阳性做
  IEDB↔结构的桥。665 条带 PDB 阳性 → 652 个不同 PDB、200 个抗原 accession，
  **200/200 全部有同抗原阴性**（合计 20,799 条），头部是 α-synuclein、APP、
  tau、HIV Gag——正是战役目标类。

**v3 家族单位**：(PDB 复合物 = 抗体上下文) × (同抗原 IEDB 阳性 = binder 证据) ×
(同抗原阴性，组成匹配 + 位置去混淆)。组装试点从"前 8 体量抗原"改为
"v3 结构桥队列"，规则修正（位置去混淆）先行。

## 3.7 v3 试点结果（2026-10-31 冻结）：精确组成匹配的产率墙

`pilot_v3_summary.json`：200 个结构桥家族全量组装，**仅 1 个通过**（binder ≥2
且池产率 ≥0.5），平均产率 0.96%；同抗原位置匹配总计 0，跨抗原池匹配总计 5。
机械链（取数→身份→去重→匹配）全部工作，失败在**精确组成匹配本身**：
15k 独立阴性序列的池子对 12–15 mer 的精确多重集碰撞概率天然极低——这也是
ECLS/C1 一线用"组成打乱"而非"寻找真实组成匹配序列"的隐含原因。

**冻结前的分叉（A' 已测试并证伪，2026-10-31）**：
- **A'（保持规则，扩池）——已执行，已证伪**：全库阴性池建成并冻结
  （`negative_pool_summary.json`：123.5 万条记录 → 709,890 独立序列、
  672,336 个不同组成，平均每组成类 1.056 个序列）。v3b 匹配
  （`pilot_v3b_summary.json`）：产率 0.96% → 1.63%，通过家族仍 1/200，
  339 个 binder 仅 8 个匹配。**精确组成匹配在任何可达池规模下不可行**——
  组成空间稀疏度决定的数学事实，非工程问题。
- **A（放宽规则，剩余可选项）**：组成最近邻匹配（同长度、20 维组成 L1 距离
  最小、位置去混淆保留）。控制质量弱于精确匹配，预注册必须定义可接受距离并
  让组成基线同台受试——注意 C1 已证明该基线曾击败裁判，此路主张必须降格。
- **B（终止，倾向项）**：按"公共数据不足以支撑诚实严格度"记录缺口，Phase D
  终结于边界研究手稿（已成稿）。A' 的证伪使 B 的论据从"未试"变为
  "已测得的数学事实"。
