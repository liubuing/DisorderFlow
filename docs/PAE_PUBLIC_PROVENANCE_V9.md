# 公共候选的训练来源、抗原关系与化学完整性审计

日期：2026-09-18。已完成本轮审计。结论：原7组中保留6组、11个化学条件兼容的结构，归为4个生物学抗原类别；只能支持明确披露重叠的回顾性描述评估，不能作为6个严格独立抗原。未启动新AF2评分。

## 实际使用记录

Ridge 使用原15个训练组件；另有2个校准组件及6个已暴露开发组件。本轮只核查序列和成员元数据，没有读取历史封存测试标签，也没有使用新PAE标签。

候选生成器的冻结谱系显示：stage A从随机初始化，在 `data/phase3_v5_1_pair_clustered/train.lmdb` 训练、以对应val库验证；stage B在DisProt/AFDB监督数据上训练。本轮直接扫描stage A的train/val记录并记录库文件哈希，不把混合历史参考库中所有记录都称作实际训练样本。stage B及上游ProteinMPNN训练成员没有完成逐条穷尽审计。

原7组所有成员的PDB编号均未在该stage A train/val库中精确命中，但部分候选的抗原片段出现在训练蛋白序列中。因此“PDB没有重合”不足以支持“抗原未见过”。

## 短肽匹配的含义

真实片段关系与偶然低一致性必须分开。NANP重复基序、AVGIGAVF融合肽及V3完整子串都有具体序列证据。双向80%覆盖率规则会漏掉短肽与长抗原的包含关系，例如7aa肽包含于18aa重复肽时，即使短肽完全相同也不满足双向覆盖率；因此原MMseqs通过不能单独证明新抗原。

另一方面，“3个或4个残基相同”不自动证明生物学同源。本轮对原代表肽做1000次保留组成的随机打乱，仅与15个Ridge训练抗原比较。4XMK达到至少30%最大一致性的打乱比例为32.3%，说明低阈值命中本身可能不具特异性。这是描述性诊断，不是同源性检验、不改变原筛选门槛，也不抵消已确认的片段重叠。非标准肽原序列的打乱结果不用于资格判定。

## 上游模型边界

[AlphaFold官方技术说明](https://github.com/google-deepmind/alphafold/blob/main/docs/technical_note_v2.3.0.md)给出该代Multimer更新的训练截止日期为2021-09-30。这批结构全部早于该日期，不能宣称时间隔离；日期早于截止也不等于已经证明逐条在训练集中。精确AF2训练成员、ProteinMPNN训练成员仍未知。

[5DMG官方条目](https://www.rcsb.org/structure/5DMG)确认抗原为磷酸化Tau并列出SEP；[4XMK官方条目](https://www.rcsb.org/structure/4XMK)确认其为gp120 V3肽。其余生物类别依据下载的RCSB题名、链元数据及逐条抗原序列关系记录，4类只是生物学分层，不是独立家族数的统计证明。

## 具体决定

这6组可以作为下一份**回顾性、按抗原类别分层的描述性筛选实验**的候选输入。CSP的3组不能作为3个独立抗原计数；已知家族与其他候选必须分别报告。该实验可以回答已知抗原上的筛选可迁移性，不能证明跨全新抗原泛化，也不能单靠它支持一区/二区新方法优越性主张。

本阶段已准备化学修正后的候选包，`ready_for_scoring=false`：下一实验还需先冻结候选生成、筛选预算、教师重复数、随机基线、组件/抗原类别汇总和失败处理规则，再计算标签。不是等待用户提供文件或重复授权，也没有后台GPU任务。
