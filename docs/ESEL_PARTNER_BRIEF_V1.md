# ESEL 湿实验伙伴简报（展示选择外包征询）

日期：2026-11-04。随 `docs/ESEL_E1_LIBRARY_PREREG_DRAFT_V1.md` 使用。
本简报只谈需求与验收，不含任何"结合预测"承诺——筛选与测量由实验承担。

## 我们要什么

1. **合成 VHH 或 scFv 展示文库的 panning 筛选**（酵母或噬菌体，对方建议为准），
   目标抗原为 2–4 条**无序/柔性肽段**（6–20 aa，冻干多肽，生物素化标记），
   按我们提供的**呈现矩阵**执行（游离肽 / 末端生物素位置 / 可选乙酰化）；
2. **逐轮 NGS 测序**（建议 3 轮，输入库 + 每轮输出库，≥10^5 reads/轮）；
3. **Top 12–24 克隆的表达与 BLI/SPR 动力学测量**（对相应肽段出 k_on/k_off/Kd）。

## 我们提供什么

- 表位肽清单 + 呈现方案（`results/esel_e0_v1/epitope_presentation_matrix.json`，
  每表位含全长/核心截短/两种生物素取向变体）；
- 文库设计规格（E1 冻结版）：CDR-H3 长度/电荷/疏水的条件分布，按表位属性分桶；
  可由对方现有骨架库实现，也可按规格定制合成；
- 阳性/阴性对照设计（native 复合物序列 + 无关 scFv + 组成扰动肽）；
- 全部序列、协议、判定的机器可读冻结文件（供对方执行与复核）。

## 判定式（预先写明，避免事后标准争议）

- 筛选成功：任一呈现条件下第 3 轮对第 1 轮的特异性富集 fold ≥ 预注册阈值
  （E1 冻结时定值）；
- 能力达成：任一克隆对任一表位实测 Kd ≤ E1 冻结阈值（候选区间 10–100 nM）；
- 任一判据不达，不影响按实报数据结算——我们买的是执行与测量，不是阳性结果。

## 需对方确认的三件事（报价单请逐项对应）

1. **文库来源**：现成合成库（规模/多样性/骨架类型）还是按我们规格定制？
   定制的话 CDR-H3 分布规格的实现精度能到什么程度？
2. **呈现通量**：一次合作能覆盖几个表位 × 几种呈现条件？多肽合成与生物素化
   是含在报价内还是我们另行委托？
3. **周期与数据交付**：panning 三轮 + NGS + BLI 的总周期；NGS 原始数据与
   BLI 传感图原始文件是否完整交付？

## 边界声明（对方知悉）

- 目标是**无序/柔性表位**，筛选失败是预期内的可能结果之一，呈现矩阵已按此设计
  多条件冗余；
- 全部设计数据目前**零实验验证**，筛选结果将作为第一手实验数据回填我方记录
  （组成受控富集数据，用于后续方法校准）；
- 我方默认所有交付数据可进入公开发表的边研究/方法论文，如对方有数据保密要求
  请在报价前说明。
