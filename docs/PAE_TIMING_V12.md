# PAE v12 同硬件计时

本实验比较从现有候选池到AF2结果的实际墙钟时间。冻结方案位于 `results/pae_timing_v12/protocol.json`。

- 筛选路线：120条候选读取、设计PDB特征提取、冻结Ridge排序，保留24条，运行144个AF2模型/种子任务。
- 全量路线：120条候选，运行720个AF2模型/种子任务。
- 两条路线均使用模型1/2、种子7103/7111/7121、3次recycle和同一台GPU；每条路线从新的输出目录启动，不复用历史AF2结果。
- 计入工作进程启动、预热、输出和校验；不计共同的候选生成、共享Python导入和计时前的权重校验。不能称为完整的生成至评价加速，也不能将墙钟时间当作GPU活跃计算小时。
- 只测一对，固定先筛选后全量；系统缓存、温度及执行顺序影响尚未通过重复实验估计。

2026-09-20首次启动因沙箱WSL访问限制失败，未得到有效AF2结果。失败目录保留为 `failed_screened_permission_attempt_01`，状态保存为 `failed_permission_status_01.json`。随后使用已授权的沙箱外执行重新启动；失败启动不计入有效计时对。

当前阶段必须读取 `status.json` 确认。只有两条路线全部完成且输出校验通过后，才会生成 `comparison.json`；在此之前不报告实测节省比例。后台日志为 `stdout_attempt02.log` 和 `stderr_attempt02.log`。
