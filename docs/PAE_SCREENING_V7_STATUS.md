# PAE 筛选路线：冻结与成本核算

日期：2026-09-18。本阶段已完成；独立新抗原验证未启动，原因是现有检索规则下没有未暴露的新候选。

## 已执行

从原 v4 训练划分重建并导出 Ridge（alpha=10）及标准化参数，未使用 v6 标签重新训练。选择该模型时已知 v4–v6 的开发结果，因此这是开发后冻结，不能称为从未看过结果的模型选择。模型、训练缓存及协议均留存 SHA256。

固定每个组件保留预测 PAE 最低的 20% 候选，向上取整；同分按 entity_id 排序，对照不占筛选预算。独立验证仍要求结构资格、五轴同源隔离、短序列敏感性检查和预训练重叠审计。6 组件、3 抗原家族只是最低可行性要求；在功效审查完成前不得开始新标签计算。

## 测得的成本与效果

CPU 上从设计 PDB 解析、构建输入、提取组成和几何特征到预测并排序，每个骨架的 82 个实体（80 候选和2对照）耗时中位数为 **0.111–0.214 秒**。每组一次预热、五次测量；不含解释器和依赖导入，模型加载另计。六组中位数合计约 **1.095 秒**，这是中位数之和，不是一次全流程墙钟计时。

新提取特征与原缓存一致，预测与 v6 Ridge 结果在绝对容差 2e-5 内一致，选出的96条候选 ID 完全一致。480 条候选筛选为96条，在已暴露的开发面板上对应此前 **69.8% 的前20%召回率**；这同时意味着约30.2%的真正前20%候选未保留，不是无损加速。

按骨架、完整重轻链和抗原序列、AF2模型及种子去重后：

| 计算量 | 全部候选 | 筛选后候选 |
|---|---:|---:|
| 唯一 AF2 槽位 | 2,670 | 510 |
| 已记录 AF2 elapsed 合计 | 41,943.322 秒 | 7,784.884 秒 |

可避免的槽位约80.9%，历史 elapsed 回放减少约81.4%。此处只统计候选，不含12条对照；同序列跨生成方法只计算一次，不能将480×6简单当作实际任务数。

**这些是已有 AF2 记录的回顾性成本回放，不是实测端到端加速。** 历史缓存与本轮记录混合，未计生成、AF2预热、重试、排队、进程开销，也未进行硬件归一化。没有为取得成本数据重新运行 AF2。

## 新抗原检索结果

将此前增量 RCSB 检索截止日期更新到2026-09-18，返回45条元数据，原结构规则下5个候选；与历史元数据排除集合核对后，未暴露候选为0。因此没有新的独立抗原组件，也没有启动独立队列的模型评分或 AF2 教师计算。

原范围为配对重轻链抗体与5–50 aa肽，包含病毒条目；此前2025年以来的大窗口审计已完成，本次核查其后增量。零结果不代表全球不存在可用数据。不得在看到零结果后放宽排除规则，并继续沿用“独立确认”名称。

## 当前决策

工具的筛选成本较低这一点已有实测支持；筛选有效性仍限于已暴露开发面板。下一项关键证据需要新结构/合作数据来源。若扩展到蛋白抗原或回顾性队列，须先单独定义适用范围和分析方案，不能直接替代原肽任务的独立验证。当前没有后台 AF2 任务，也没有设置等待新数据的自动监测。
