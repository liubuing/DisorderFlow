# BBB 芯片自建实验方案（PDMS 软光刻，最低配置）

## 一、概述

本方案用 PDMS 软光刻制作简易血脑屏障（BBB）微流控芯片，用于验证 BFN 设计的脑病抗体穿透率。采用 Transwell-like 双层通道结构，上层为 hCMEC/D3 内皮单层（模拟 BBB），下层为星形胶质细胞（可选）。

**周期**：3-4 周 | **预算**：~5-8 万（不含洁净室，用学校微纳平台）

## 三、制作流程

### Step 1：光刻掩膜设计

使用 AutoCAD / CleWin / KLayout 绘制：

```
上层通道（血液侧）：宽 200 μm × 高 100 μm × 长 1 cm
下层通道（脑侧，可选）：宽 500 μm × 高 100 μm × 长 1 cm
两通道之间：PDMS 薄膜 ~50 μm（多孔膜替代方案）
圆形出入口：直径 2 mm（打孔器匹配）
```

掩膜打印在透明菲林上（分辨率 ≥ 20,000 DPI，华大基因/昆山均可）。

**简化版**：单通道 + Transwell 膜的替代表面处理，不需要下层通道。

### Step 2：SU-8 模具制作

```
(1) 硅片清洗：丙酮超声 5 min → IPA 超声 5 min → DI water rinse → 热板 200°C 脱水 10 min
(2) 旋涂 SU-8 2050：
     500 rpm 10 s（展开）→ 3000 rpm 30 s（目标膜厚 ~100 μm）
(3) 前烘（Soft Bake）：
     65°C 5 min → 95°C 15 min → 缓慢冷却至室温（防龟裂）
(4) UV 曝光：
     将掩膜贴紧（或真空接触），365 nm UV，剂量 ~200 mJ/cm²
     （无掩膜对准器：用 UV 灯 + 石英玻片压紧，曝光时间由预实验校准）
(5) 后烘（Post Exposure Bake）：
     65°C 3 min → 95°C 7 min → 冷却
(6) 显影：
     SU-8 Developer（PGMEA）浸泡，轻柔摇动 5-8 min
     → IPA 冲洗 → 可见通道图案清晰
(7) 硬烘（可选）：150°C 15 min（增强模具耐久性）
(8) 防粘处理：滴 50 μL 三氯硅烷于玻片，与硅片同放真空皿中，抽真空 1 h
    （或涂 Sigmacote，晾干）
```

**关键检查点**：显影后显微镜下测量通道宽度，误差应 < ±10 μm。

### Step 3：PDMS 倒模

```
(1) Sylgard 184 主剂:固化剂 = 10:1（质量比），玻璃棒搅拌 5 min
    → 倒入一次性培养皿 → 真空干燥器脱气 30 min（气泡全消）
(2) 将模具放入铝箔小盒，缓缓倒入 PDMS，高度 ~5 mm
(3) 再次脱气 15 min
(4) 烘箱 65°C 固化 2 h（不过夜，避免过度交联变脆）
(5) 冷却后用手术刀沿模具边缘切下 PDMS 块
(6) 用 20G 打孔器在出入口标记处垂直打孔，穿透到底
```

### Step 4：等离子键合

```
(1) 将 PDMS 通道面朝上 + 玻片，放入等离子清洗机
(2) O₂ plasma：30 W，30 s，真空度 ~0.5 mbar
(3) 取出后立即（30 s 内）将 PDMS 通道面贴到玻片上
(4) 轻压排出气泡 → 热板 95°C 10 min 增强键合
(5) 插管：将特氟龙管插入出入口孔，如松动可用 PDMS 预聚物密封
```

### Step 5：通道涂层

```
(1) 注入 70% 乙醇消毒 30 min
(2) PBS 冲洗 3 次
(3) 注入纤连蛋白溶液（50 μg/mL in PBS），37°C 孵育 2 h
    （可选：Collagen IV 50 μg/mL 增强细胞贴附）
(4) PBS 冲洗 1 次，移除多余蛋白
```

## 四、细胞接种与培养

### 4.1 hCMEC/D3 内皮接种

```
(1) 常规培养 hCMEC/D3 于 T75 瓶（EBM-2 + 5% FBS + 生长因子）
    → 胰酶消化 → 计数 → 重悬至 5×10⁶ cells/mL
(2) 缓慢注入细胞悬液到通道（~10 μL），显微镜确认均匀铺展
(3) 37°C 5% CO₂ 静置 4 h，让细胞贴壁
(4) 翻转芯片（通道朝下），37°C 过夜（防止细胞在下壁沉积）
    → 再翻转回来继续培养
(5) 低流量灌注：0.5 μL/min（0.1 dyn/cm² 剪切力），培养 5-7 天
    （若无注射泵，用摇床倾斜 15° 每 5 min 换向，重力驱动）
```

### 4.2 BBB 成熟判定

每日测量 TEER（跨内皮电阻）：

| 天数 | 预期 TEER |
|------|----------|
| Day 1 | 30-50 Ω·cm² |
| Day 3 | 100-150 Ω·cm² |
| Day 5 | 200-300 Ω·cm² |
| Day 7 | 300-500 Ω·cm² |

**可用标准**：TEER > 200 Ω·cm² + FITC-Dextran 4 kDa 渗透系数 < 5×10⁻⁶ cm/s。

### 4.3 星形胶质细胞共培养（可选，增强 BBB 特性）

```
(1) 先在下层通道接种星形胶质细胞（U87 MG，2×10⁵ cells/mL），培养 24 h
(2) 翻转芯片，在上层通道接种 hCMEC/D3
(3) 双向灌注独立循环（上层血液侧、下层脑侧）
    → BBB 特性增强：TEER 可达 500-800 Ω·cm²
```

## 五、抗体穿透实验

### 5.1 实验流程

```
(1) EBM-2 无血清培养基洗通道 3 次（去除血清蛋白干扰）
(2) 在上层通道（血液侧）注入荧光标记抗体溶液（FITC 或 Alexa Fluor 488）
    浓度：10-100 μg/mL in EBM-2 无血清
    体积：50 μL
(3) 下层通道（脑侧）持续收集流出液（1 μL/min × 60 min）
(4) 在 96 孔板中测量荧光强度（ex 488 / em 520）
    → 标准曲线推算渗透抗体浓度
```

### 5.2 渗透系数计算

```
Papp = (dQ/dt) / (A × C₀)

dQ/dt：下层通道中抗体随时间累积的速率（mol/s）
A    ：通道界面面积（宽 × 长，cm²）
C₀   ：上层通道初始抗体浓度（mol/mL）

Papp 单位：cm/s
```

### 5.3 验证对照

| 对照 | 条件 | 预期 Papp |
|------|------|----------|
| 阳性对照 | FITC-Dextran 4 kDa（旁路示踪） | 5-15 × 10⁻⁶ cm/s |
| 阴性对照 | FITC-Dextran 70 kDa（不应穿过） | < 1 × 10⁻⁶ cm/s |
| 无细胞对照 | 空白 PDMS 通道（仅涂层） | 抗体自由扩散值 |
| 已知 BBB 穿透抗体 | OX26（转铁蛋白受体抗体） | ~3 × 10⁻⁶ cm/s |

### 5.4 细胞毒性同步评估

```
(1) 抗体灌注 24 h 后取上层培养基
(2) LDH 释放检测（CyQUANT LDH Cytotoxicity Assay Kit）
    → LDH 释放 > 20% 判断为细胞毒性
(3) 活/死染色（Calcein AM + PI）可视化确认
(4) TEER 恢复测试：洗掉抗体后继续培养 24 h，测 TEER 是否恢复
```

## 六、BFN ↔ 芯片数据对接

### 6.1 每条候选抗体的芯片数据输出

```python
{
    'sequence': 'QVQLVESG...',    # BFN 生成的 CDR 序列
    'pdb_id': 'design_001',        # 设计编号
    # BFN 计算侧
    'af2_iptm': 0.89,
    'af2_plddt': 0.92,
    'rosetta_dG': -45.3,           # kcal/mol, InterfaceAnalyzer
    # 芯片实验侧
    'chip_teer_baseline': 320,      # 加抗体前 TEER (Ω·cm²)
    'chip_teer_24h': 280,           # 加抗体 24h 后 TEER
    'chip_papp': 2.3e-6,            # 渗透系数 (cm/s)
    'chip_ldh_release': 8.5,        # LDH 释放率 (%)
    'chip_z0i_score': 0.6,          # 紧连接蛋白 ZO-1 免疫荧光（可选）
}
```

### 6.2 芯片综合评分 (Chip Score)

```
Chip_Score = w1 × norm(Papp⁻¹) + w2 × norm(ΔTEER⁻¹) + w3 × norm(LDH⁻¹)

其中：
  Papp⁻¹  → 穿透率越高分越高（1/Papp）
  ΔTEER⁻¹ → TEER 下降越少分越高
  LDH⁻¹   → LDH 释放越少分越高
  w1=0.5, w2=0.3, w3=0.2

Chip_Score ∈ [0, 1]，越高越优
```

## 七、一个最小化方案（无洁净室替代）

如果没有微纳加工平台，可以用最低配置搭一个功能性 BBB 模型：

| 替代 | 方案 |
|------|------|
| PDMS 芯片 | Transwell 插件（Corning 3470, 0.4 μm pore PET） |
| 微流控流动 | 摇床倾斜培养（重力驱动）或静置 |
| hCMEC/D3 | 初次用 MDCK-MDR1（更易养，可测 P-gp 转运）|
| 注射泵 | 移液枪定时换液 |

**Transwell 替代流程**（2 周搭建）：
```
Transwell 插件 → 纤连蛋白涂层 → 种内皮 → 养 5 天 → TEER > 200 → 
上层加抗体 → 下层取样 → ELISA/荧光检测 → LDH 毒性
```

这个方案没有剪切力（影响紧密连接形成），但能给你第一条芯片反馈数据，验证 BFN 闭环可行性。
