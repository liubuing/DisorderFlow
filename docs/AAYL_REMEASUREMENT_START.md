# 补测启动准备与来源复核

日期：2026-09-16。已完成原始数据补查和首批草案；尚未提交实验、订购构建体或获得新实验读数。

## 已执行的补查

重新扫描固定版本的两个 AlphaSeq 原始数据集，按重链＋轻链序列精确匹配 748 个待核查构建体，并保留原来的 POI、靶标、实验批次和重复编号。

- 120 个构建体在原实验中有匹配记录，包括 118 个已知不完整候选和两个亲本。
- 57 个构建体在其他实验批次也有匹配；与上一项存在重叠。
- 604 个构建体在这两个来源中均无精确匹配；不代表所有公共来源均不存在。
- 118 个不完整候选未找回可唯一补齐原三重复的记录。不同批次的数据没有合并进原有标签。
- 两个亲本找到了完整的控制记录，但各有多个同序列 POI；这是控制身份/构建形式需核对的问题，不能写成“亲本无测量”。保留逐组记录，未任意选择或合并成一个端点。

机器记录：[source_recovery.json](../results/aayl_remeasurement_v1/source_recovery.json)。它是历史来源复核，不是新补测结果。

## 首批草案

两个谱系各选三个三突变组合。每个组合配套完整八成员：亲本、三个单突变、三个双突变及三突变。共享构建体去重后每个谱系 20 个，共 **40 个构建体**。

优先选择边际新增构建体较少、同时覆盖更多已知不完整候选的组合；不按亲和力结果挑选“好看”的候选。已有完整历史值的配套构建体也保留在本批，以便同条件比较。

| 谱系 | 三突变来源 POI |
|---|---|
| AAYL49 | AAYL49_28986、AAYL49_28973、AAYL49_28974 |
| AAYL51 | AAYL51_29504、AAYL51_29537、AAYL51_29571 |

暂按每个构建体三次独立观测，预计 **120 条变体观测**。该数目不是孔位数或仪器运行次数，不含滴定浓度系列、空白、平台参考/特异性对照及失败重测；实际安排须依据可用平台和预算。三个重复的具体独立层级需由实验方案定义。

- [首批设计与配套映射](../results/aayl_remeasurement_v1/pilot_design.json)
- [重/轻链可变区 FASTA](../results/aayl_remeasurement_v1/pilot_variable_domains.fasta)
- [空白读数模板](../results/aayl_remeasurement_v1/blank_readout_template.json)

FASTA 是配对可变区氨基酸序列，不是可直接下单的完整表达构建体。原数据的 scFv 重轻链顺序、linker、标签/表达形式与拟用平台须核对后才能制作正式构建方案；当前没有推定这些参数。靶肽身份在设计文件中保留，具体固定化、标记及呈递形式亦未擅自指定。

## 启动实际测量仍需的信息

需要可用实验平台/实验室、首批构建体或经费预算，以及现有抗体和靶标材料信息。当前没有连接实验仪器或实验执行机构，无法从本地计算产生真实新读数。用户确认这些条件后，才能形成适配平台的正式交接方案。

如当前仅具备计算条件，可以继续单独分析其他批次的匹配数据，但这属于回顾性补评估，不能称为新实验补测。缺失读数不得填充为猜测的亲和力。

复现：`python scripts/prepare_aayl_remeasurement.py --prepare`，随后 `--run`。已冻结来源哈希、精确匹配和首批选取规则。
