# CSN C3：ESEL RFQ 呈现加列提案 v1

日期：2026-11-08。**状态：提案——决定权在用户与湿实验伙伴**；本文件不改
ESEL 询价包（`docs/ESEL_RFQ_PACKAGE_V1.md`），只提出加列建议与理由。
科学依据全部来自 CSN C0/C2 冻结产物（`results/csn_c0_v2/`、`results/csn_c2_v1/`）。

## 1. 依据（一段话）

C0 显示：tau PHF6*（GSVQIVYKPK）上三个独立沉积的结合者读到**同一主链构象**
（成对 RMSD 0.098–0.157 Å，达 NCS 拷贝量级）——即"该构象态是被选择的"有了
deposit 层面证据；C2 显示 J0b 生成 conformer 携带真实运动（中位 0.445 Å）。
若展示选择能在**不同呈现态**之间产生可区分的富集谱（CSN H3），ESEL 就从
"找结合者"升级为"构象态分辨的免疫读出仪器"。

## 2. 加列建议（按成本递增）

| 列 | 内容 | 成本/风险 | 能裁决什么 |
|---|---|---|---|
| A1（最廉价） | **tau PHF6\* 行纳入 RFQ**（若短名单备用行未含）：GSVQIVYKPK 肽，full/core_15/biotin-N/C 变体照 ESEL 现行规格 | 与现行短名单行同规格；tau 肽无生物安全旗标 | C0 主检验表位首次进入实验管线；H3 分布 vs ESEL 现行神经行（α-syn/Syt1）的分布对比 |
| A2 | 同一 GSVQIVYKPK 肽的**聚集态呈现**：新配单体 vs 预聚集/超声处理肽原纤维（同一肽、两个呈现态，冻干分装） | 仅多一管肽与一个处理步骤；无新生物安全项 | **最低成本的"态×富集谱"判别**（H3 的肽级版本） |
| B（二期，重） | 全长 α-syn 单体 vs PFF（预制纤维，标准方案）呈现 | 需蛋白表达/购买 + PFF 方案 + 生物安全审阅升级 | 蛋白级构象态判别；对接 prasinezumab 邻区的临床叙事 |

## 3. 边界（必须保留）

- 本提案**不改变** ESEL 的选择器（展示富集）、门（≥10×/轮）与能力终点
  （T\*=100 nM）；加列只增加呈现矩阵的列数与对照维度；
- A2 的"预聚集"必须附 QC（ThT 或 TEM 拍照），否则"态"不可声称——
  写进伙伴简报的验收标准；
- 呈现态差异的富集谱对比是**能力读出**，不是疾病机制主张（N2 纪律）；
- C0 的"构象共享"是 deposit 层面描述，不预测展示富集方向——富集结果
  两种方向都可发表。

## 4. 用户决策点

1. 是否把 tau PHF6\* 行加入 RFQ（A1）；
2. 是否接受 A2 的预聚集 QC 要求（ThT/TEM）；
3. B 列是否排入二期（取决于伙伴通量与生物安全审阅范围）。
