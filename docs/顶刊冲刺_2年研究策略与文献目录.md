## A.1 重新定义目标：顶刊审稿人的三个核心问题

顶刊拒稿通常会写"story 不够完整"或"机制不够深入"。翻译过来真正的问题是这三个：

| 审稿人真正想问的 | 你的项目必须回答的 |
|------------------|-------------------|
| **为什么是你？** 这个 cargo 凭什么比别人好？海参肽有什么独特机制？ | 海参肽不是"又一个抗氧化肽"，它的某条具体序列有独特的作用靶点（HDAC3？Aβ 直接结合？Nrf2？），你需要把分子机制做到 residue-level |
| **为什么靠谱？** 你怎么保证这不是又一个"小鼠有效、人没用的"递送系统？ | 人源化 VHH + 人 TfR 亲和力 + 人 BBB 细胞模型 + 人源化 AD 模型（至少 APP 敲入），每一层去掉一个"可能在临床上不成立"的假设 |
| **为什么是你来做？** BFN 设计相对于传统淘选到底带来了什么不可替代的优势？ | BFN 优化后的 VHH 不只是"亲和力高一点"，而是解决了某个传统方法解决不了的问题（比如：避免了某个安全性差的结合表位、实现了人/鼠交叉反应性、或设计出全新 CDR 结合模式） |

## A.3 各 Phase 的顶刊级要求

### Phase 1：学习期（月 1-3）—— 不再是"了解"，是"精通"

**目标**：3 个月后，你能在自己的项目上做出独立判断，而不需要别人告诉你"这个方向对不对"。

**必须达到的能力**：
- 拿到任何一条 VHH 序列，能标注 CDR、判断人源化程度、预估可表达性
- 看到一篇新的 TfR BBB 递送论文，能立刻判断跟自己的项目有什么差异、自己的优势在哪里
- 能独立跑通 AlphaFold → 对接 → MD 的工具链

**每周学习计划**（共 12 周）：

| 周 | 主题 | 核心任务 |
|:--:|------|---------|
| 1-2 | 蛋白质结构基础 | 20 种氨基酸理化性质记住；二级结构识别；PDB 文件操作；PyMOL 基本操作 |
| 3-4 | 抗体与纳米抗体 | IgG 结构 → VHH 结构 → IMGT 编号 → 人源化策略 → 骆驼 VHH 与人的差异 |
| 5-6 | AD 病理 + BBB 生物学 | Aβ 假说、tau 假说、BBB 结构、RMT 机制、TfR 在 BBB 的角色 |
| 7-8 | BFN + 结构预测工具 | BFN 原理理解、AntiFold/AlphaFold/ESMFold 实操、序列评估 |
| 9-10 | 分子对接 + MD | HDOCK/HADDOCK 实操、GROMACS 跑通 lysozyme tutorial |
| 11-12 | 文献整合 | 写一篇 5000 字的"领域现状与我的项目定位"综述（不发表，给自己看） |

---

### Phase 2：BFN 设计（月 4-6）—— 不是"设计几个候选"，是"回答为什么你的 VHH 比别人好"

**顶刊级别的设计要求**：

1. **不只做模板优化**：至少有一个候选的 CDR3 是 BFN 从零生成的（de novo CDR3），与任何已知序列 identity < 60%
2. **表位差异化**：用对接证明你的 VHH 结合在 TfR 的 apical domain 且不与转铁蛋白竞争位点重合（这关系到安全性——不影响铁代谢）
3. **人/鼠交叉反应性**：BFN 设计时约束 CDR 识别 TfR 的人/鼠保守表位（体内实验用小鼠，不能人鼠不交叉就没法做体内）
4. **能量分解**：做 per-residue 能量分解，知道 CDR 里哪几个残基贡献了 >80% 的结合能——这些残基在后续突变验证中必须验证

**输出不再是"5-10 条候选"，而是**：
- 2-3 条 lead VHH，每条有完整的：序列、结构预测、对接构象、能量分解、与已报道 VHH 的表位对比
- 一个明确的"为什么 BFN 设计优于传统淘选"的论证（这是 Nat Commun 审稿人会问的）

---

### Phase 3：表达纯化（月 7-9）—— 多做一个质量控制

旧方案达标即可：SDS-PAGE >95% 纯度、SEC 单体 >90%、CD 光谱正常、LC-MS 分子量确认。

**顶刊额外要求**：
- **内毒素含量** < 0.1 EU/μg（用于细胞实验时标注）
- **批间一致性**（至少两批独立纯化的蛋白，活性数据取均值 ± SD，n ≥ 3 独立实验）
- 如果表达量低（< 5 mg/L），需要做一轮序列优化（如 N 端或 C 端截短、表面残基突变）——并把这个过程写进论文，证明你解决了实际问题

### Phase 4：体外验证（月 10-12）—— 加三个深度实验

旧方案的五项基础实验（SPR、BBB 穿越、Aβ 抑制、抗氧化、细胞毒性）全保留。

**顶刊新增的三个深度实验**：

#### 新增 1：VHH-TfR 结合表位精细鉴定

```
目的：证明你的 VHH 不只是"结合 TfR"，而是结合在"对 BBB 穿梭最优的表位"

方法（不需要 Cryo-EM）：
1. 丙氨酸扫描（alanine scanning）：CDR3 的每个残基单独突变为 Ala
   → SPR 测量 ΔΔG，找出热残基（hot spot）
2. TfR 胞外域片段竞争实验：表达 TfR 的不同结构域片段
   → 验证 VHH 结合在 apical domain 而不是 protease-like/helical domain
3. 与转铁蛋白的竞争 SPR：VHH 结合 TfR 时，转铁蛋白能否同时结合？
   → 如果互不干扰 → 安全性通过（不影响铁摄取）
```

#### 新增 2：Cargo 分子机制验证

```
目的：回答"海参肽凭什么能治疗 AD？"——不只是"它有抗氧化"，而是具体的分子靶点

三条通路至少验证一条（选最有把握的）：

通路 A（HDAC3）：
  - 细胞热迁移实验（CETSA）：海参肽处理 SH-SY5Y 细胞后，HDAC3 的热稳定性是否改变？
  - 如果 CETSA 阳性 → 证明 peptide 直接结合 HDAC3 → 这是新发现，可以单独发一篇
  - 如果 CETSA 阴性 → HDAC3 是间接调控（通过菌群-肠-脑轴），不是直接靶点

通路 B（Aβ 直接结合）：
  - SPR/BLI：固定 cargo 肽，流过 Aβ₁₋₄₂ 单体/寡聚体/纤维 → 测 Kd
  - 分子对接 + 突变验证：预测 peptide 在 Aβ 上的结合位点 → 突变 peptide 的关键残基 → ThT 验证活性丧失
  - TEM/AFM 成像：peptide 存在下的 Aβ 纤维形态变化

通路 C（Nrf2/ARE 抗氧化通路）：
  - 双荧光素酶报告基因（ARE-luciferase）：peptide 处理 → Nrf2 转录活性是否上调？
  - WB：Nrf2、HO-1、NQO1 蛋白水平
  - Nrf2 siRNA 敲低后 peptide 的保护作用是否消失？
```

**优先级建议**：通路 B（Aβ 直接结合）最可控，不依赖动物，最容易在 2-3 个月内拿到明确结论。做完 B 再看是否有余力做 A。

#### 新增 3：血清稳定性时程

旧方案只做了一个 24h 时间点。顶刊需要更精细的数据：

```
时间点：0, 0.25, 0.5, 1, 2, 4, 8, 24, 48h
温度：37°C
血清：小鼠血清 + 人血清（平行做）
检测：Western blot（完整蛋白比例）+ 保留的 TfR 结合活性（SPR，看降解后还有没有功能）
输出：半衰期 t₁/₂（小鼠 vs 人）、降解产物分析（如果有 >3 条降解带 → LC-MS 鉴定切点 → 后续序列优化）
```

### Phase 5：机制深挖（月 13-16）—— 这是顶刊的胜负手

这个 Phase 是旧方案里没有的。**普通刊 vs 顶刊的核心差别就在这里。**

做完 Phase 1-4，你已经有了"这个融合蛋白有效"，但还缺"它为什么有效？比别人的好在哪？"

这个 Phase 的目标是让审稿人看完后说"好吧，机制清楚，没有悬而未决的问题"。

#### 实验 1：脑组织蛋白质组/转录组（推荐蛋白质组）

```
目的：融合蛋白治疗后，AD 小鼠脑内到底发生了什么分子层面的改变？

设计：
- 3 组：WT 对照、APP/PS1 + PBS、APP/PS1 + 融合蛋白
- 每组 n=3-4
- 海马 + 皮层分别取材
- 4D-DIA 定量蛋白质组（现在便宜，一个样本 ~500-800 元）

分析：
1. 差异蛋白 GO/KEGG 富集 → 验证 cargo 的预期通路是否被调控（Aβ 清除、氧化应激、突触功能）
2. 意外发现的通路 → 你的独特性就在这里（也许发现 peotide 调控了某个没人报道过的通路）
3. 与已发表的 AD 队列脑蛋白质组数据对比 → 证明你的融合蛋白逆转了 AD 的特征性分子改变
```

**这个实验的分量**：如果你能展示融合蛋白治疗后在蛋白质组层面逆转了 AD 脑的特征性病理改变——这直接就是 Nat Commun 的 Figure 5-6。

#### 实验 2：TfR 结合模式的深度表征

```
除了 alanine scanning（Phase 4 已做），再加：

1. TfR 糖基化对结合的影响：
   - 用 PNGase F 去糖基化的 TfR → SPR 测亲和力变化
   - 因为 TfR 在 BBB 上是高度糖基化的，需要确认 VHH 结合不受糖基化影响

2. pH 依赖性：
   - TfR 内吞后经历的内涵体酸化（pH 7.4 → pH 5.5）
   - 你的 VHH 在不同 pH 下的 TfR 结合亲和力如何？
   - 理想情况：pH 7.4 结合强（细胞表面捕获），pH 5.5 结合弱（内涵体释放）→ 这是最好的穿梭体特征
   - 这直接解释了"为什么你的 VHH 穿梭效率高"
```

#### 实验 3：融合蛋白的胞内转运机制

```
目的：证明融合蛋白进入 BBB 内皮细胞后确实走了"正确的路"（RMT 穿胞途径，而不是被溶酶体降解）

方法：
1. hCMEC/D3 细胞 + 荧光标记融合蛋白
2. 共聚焦显微镜：不同时间点（5/15/30/60 min）蛋白的亚细胞定位
3. 共定位标记：
   - Rab5（早期内体）
   - Rab7（晚期内体）
   - Rab11（循环内体 → 穿胞释放）
   - LAMP1（溶酶体 — 不希望的）
4. 定量的穿胞 vs 降解比例

预期（最好情况）：
  - 5 min: 膜上 → Rab5+ 早期内体
  - 15 min: Rab11+ 循环内体（穿胞通路）> LAMP1+ 溶酶体
  - 60 min: 底室荧光蛋白（穿过去了）
```

### Phase 6：体内验证（月 17-20）—— 动物实验规模不变，但分析深度提升

动物实验的设计基本沿用旧方案（药代 + AD 模型药效），但有一些顶刊级别的升级：

| 维度 | 旧方案 | 升级 |
|------|--------|------|
| 动物数量 | C57BL/6 每组 n=3 | **n=5**（统计显著性的底线） |
| AD 模型 | APP/PS1 一种 | APP/PS1 + 如果能拿到，加一个 tau 模型（如 PS19，看 tau 病理是否改善）|
| 行为学 | Morris 水迷宫 | 水迷宫 + **新物体识别**（两个独立的行为学终点，互相印证） |
| 生物标志物 | Aβ ELISA | Aβ ELISA + **Simoa 超灵敏检测**（p-tau181/p-tau217，血液标志物，AD 领域的金标准） |
| 病理 | 硫黄素 S | ThioS + **Aβ 免疫组化 + Iba1（小胶质）+ GFAP（星形胶质）** 全套 |
| 组学 | 无 | **脑蛋白质组**（与 Phase 5 衔接，用动物给药后的脑组织做） |

**关键决策**：动物实验你需要夏老师全力支持。在做 Phase 6 之前（Phase 4 体外数据到手后），就应该跟夏老师谈"体内实验怎么做能达到顶刊标准"。

## A.4 关键决策节点

| 时间 | 决策 | 判断标准 | 行动 |
|------|------|---------|------|
| 月 3 末 | 继续还是调整方向 | 你是否能独立操作 BFN + AlphaFold + 对接全流程 | 跑通了就继续；跑不通就多花 1 个月，不急着跳 |
| 月 6 末 | BFN 设计的 VHH 是否优于模板 | 对接能量提升 ≥ 5 kcal/mol 或 CDR 结合模式有明显创新 | 如果有提升 → 进 Phase 3；如果提升不明显 → 第二轮设计或换模板 |
| 月 9 末 | 表达纯化是否顺利 | 至少 1 个候选表达量 > 5 mg/L 可溶 | 顺利 → 进 Phase 4；不顺利 → 密码子优化/换菌株/截短设计 |
| 月 12 末 | 体外数据够不够进体内 | SPR Kd < 100nM + BBB Papp > 5×10⁻⁶ cm/s + Aβ IC₅₀ < 50μM | 三项都达标 → 找夏老师谈体内实验启动；不达标 → 序列优化后再测 |
| 月 16 末 | 启动体内还是纯计算发文章 | Phase 4 体外数据 + Phase 5 机制数据是否完整 | 完整 → 进体内；不完整但计算部分很强 → 考虑纯计算 + 体外先发一篇小的，体内再加 |
| 月 20 末 | 选择哪个期刊投稿 | 体内数据质量（有脑蛋白质组 → Nat Commun；没有 → A&D；体内没做成 → JCR） | 按实际数据水平选刊，不要硬冲 |

## A.5 如果时间不够——降级策略

两年最可能出问题的是 Phase 6（体内验证），因为动物实验不可控因素多。如果到月 18 体内数据还不够好：

```
方案 1（推荐）：先投 Nature Communications，正文用计算 + 体外 + 体内初报
  → 如果审稿人要求更多体内数据 → 补实验（2-3 个月）→ 修回
  → 如果被拒 → 带着所有数据（含审稿意见）转投 Alzheimer's & Dementia

方案 2：拆分发表
  → 计算设计 + 体外验证 → Nat Commun / Sci Adv
  → 体内深度验证（蛋白质组 + 药效）→ 第二篇，Alzheimer's & Dementia

方案 3：保底
  → 全套数据（计算 + 体外 + 体内）→ JCR（IF ~10，BBB 递送领域顶刊，审稿周期短）
```

## B.2 第一层：基石文献（精读 3 遍以上，8 篇）

这些是你整个项目的"理论骨架"。PPT 里引用、论文 Introduction 和 Discussion 都要围绕这几篇展开。

### 基石 1：TfR BBB 递送的里程碑

```
Kariolis MS, et al. "Brain delivery of therapeutic proteins using an Fc
fragment blood-brain barrier transport vehicle in mice and monkeys."
Sci Transl Med, 2020, 12(545): eaay1359.
DOI: 10.1126/scitranslmed.aay1359
```
- **为什么必读**：Denali 的 Transport Vehicle 平台。定义了 TfR Fc 融合做 BBB 穿梭的范式。你的 Introduction 要从这篇讲起。
- **精读重点**：Fc 工程化怎么做的（Fc 的哪些突变调节 TfR 亲和力）、亲和力与 BBB 穿越效率的关系（不是越高越好）、灵长类数据
- **跟你项目的关系**：你的 VHH 相当于 Denali 的 Fc 的"升级版"——更小、更简单的 TfR 结合模块

### 基石 2：TfR 纳米抗体 BBB 穿梭的最新突破

```
Yin T, Yesiltepe M, D'Adamio L. "NewroBus for the brain: humanized
TfR1-targeting nanobodies with high BBB permeability and cargo transport
capacity." bioRxiv, 2025. DOI: 10.1101/2025.04.20.649139
```
- **为什么必读**：你项目的最直接竞争者。470 条 VHH → 8 个 lead，体内 BBB 穿越数据完整。你的 VHH 必须跟 NewroBus 的表位/亲和力/穿梭效率做系统对比。
- **精读重点**：VHH 筛选策略、人源化方法、哪个 VHH 的 BBB 穿梭效率最高、不同表位的 VHH 是否有安全性差异（血液网织红细胞计数）
- **跟你项目的关系**：你的差异化 = 新 cargo（海参肽 vs 他们的酶/抑制剂）+ BFN 计算设计（vs 他们的传统淘选）

### 基石 3：TfR VHH 的另一个关键竞争

```
Rué L, Jaspers T, De Strooper B, et al. "Novel human/non-human primate
cross-reactive anti-transferrin receptor nanobodies for brain delivery of
biologics." Pharmaceutics, 2023, 15(6): 1748.
DOI: 10.3390/pharmaceutics15061748
```
- **为什么必读**：BBB00533 VHH，BACE1 融合降低脑 Aβ ~40%。跟你最像的项目（VHH-治疗蛋白融合 + AD）。
- **精读重点**：BBB00533 的表位、人/猴交叉反应性、BACE1 融合后的活性保持、app 敲入小鼠的 Aβ 降低数据
- **跟你项目的关系**：直接竞争对手。你的优势：cargo 是双功能（Aβ + 抗氧化），不是单一的 BACE1 抑制；你的劣势：BACE1 机制更清楚

### 基石 4：纳米抗体圣经

```
Muyldermans S. "Nanobodies: natural single-domain antibodies."
Annu Rev Biochem, 2013, 82: 775-797.
DOI: 10.1146/annurev-biochem-063011-092449
```
- **为什么必读**：VHH 领域的奠基综述。所有基础知识都在这里。
- **精读重点**：VHH 结构特征（CDR3 长度、FR2 hallmark 残基）、骆驼 VHH vs 人 VH 的区别、人源化策略、VHH 的稳定性/可溶表达原理
- **跟你项目的关系**：你设计 VHH 时需要用到的所有基础知识

### 基石 5：AD 的 Aβ 假说——Lecanemab 临床 III 期

```
van Dyck CH, Swanson CJ, Aisen P, et al. "Lecanemab in early Alzheimer's
disease." N Engl J Med, 2023, 388: 9-21.
DOI: 10.1056/NEJMoa2212948
```
- **为什么必读**：Aβ 抗体临床成功的标志性论文。证明"清除脑 Aβ → 改善认知"这条通路是成立的。
- **精读重点**：CDR-SB 评分的变化幅度、Aβ 清除的时间线、ARIA 副作用（抗 Aβ 抗体的核心安全性问题）
- **跟你项目的关系**：Lecanemab 的成功为你的 cargo 提供了"靶向 Aβ 是有效的"这个前提。你不需要证明 Aβ 假说，只需要证明你的 cargo 能帮助清除 Aβ

### 基石 6：海参肽的神经保护——夏老师论文

```
Xia X, et al. "Sea Cucumber Egg Oligopeptides Ameliorate Cognitive
Impairments and Pathology of Alzheimer's Disease Through Regulating HDAC3
and BDNF/NT3 via the Microbiota-Gut-Brain Axis."
Nutrients, 2025, 17(14), 2312.
```
- **为什么必读**：你的 cargo 来源的直接证据。这篇论文是你所有海参肽论证的起点。
- **精读重点**：肽的制备方法、有效剂量、HDAC3 和 BDNF 的变化量、菌群-肠-脑轴的证据链、有没有肽序列信息
- **跟你项目的关系**：这是"夏老师已经证明海参肽有效"的证据，你在这个基础上做"怎么让它进脑"

### 基石 7：BFN 方法学论文

（根据你实际使用的 BFN 版本确定——如 Alex Nichol 等的 Bayesian Flow Networks 原始论文，或你项目组的 BFN V10 相关论文/技术报告）
- **为什么必读**：审稿人会问"为什么用 BFN 而不是 RFdiffusion / ProteinMPNN？"你需要能回答 BFN 的原理和优势
- **精读重点**：BFN 的数学模型、与扩散模型的区别、在蛋白质设计上的性能 benchmark
- **如果找不到发表论文**：那就需要你整理你们项目组 BFN V10 的技术文档，作为论文 Methods 的基础

### 基石 8：BBB 生物学综述

```
Pardridge WM. "Blood-brain barrier delivery."
Drug Discov Today, 2007, 12(1-2): 54-61.
DOI: 10.1016/j.drudis.2006.10.013
```
- **为什么必读**：BBB 递送领域的经典综述。虽然老了，但核心概念没变。
- **精读重点**：BBB 的结构（紧密连接、内皮细胞、周细胞、星形胶质细胞）、RMT vs AMT vs carrier-mediated、为什么 >98% 药物不能入脑

## B.6 每篇论文的阅读方法

**基石文献（读 3 遍）**：

```
第一遍（30 min）：标题 → 摘要 → 图表 → 讨论第一段和最后一段
  → 回答：这篇论文的核心发现是什么？跟我有什么关系？

第二遍（1-2 h）：全文通读，标注每个你不理解的方法和概念
  → 回答：他们怎么得出这个结论的？实验设计有什么巧妙之处？
  → 在笔记里记下：这篇论文的 3 个最关键的图和它们证明了什么

第三遍（30 min，做完你自己的项目后再回来看）：
  → 回答：现在重读有什么新的理解？你跟他们的差距在哪？他们的局限在哪？
```

**支撑文献（读 1-2 遍）**：

```
第一遍（20 min）：摘要 → 图表 → 结论
  → 回答：这篇论文的核心数据是什么？在我的论文里能拿来引用哪个论点？

第二遍（仅对特别相关的）：精读 Methods
  → 回答：他们用了什么实验方法？我能不能照搬？
```

**追踪文献（5-10 min）**：

```
看摘要 + 扫 chart → 判断"跟我有关吗？"
  有关 → 存到 Zotero，标记为"之后细看"
  无关 → PASS
```
