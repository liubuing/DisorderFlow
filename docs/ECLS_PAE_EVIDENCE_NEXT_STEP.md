# ECLS–PAE 三项补证据工作

2026-09-16。当前状态：评分冲突分解、AF2 标签稳定性分析、120 条近天然困难对照的三种子评分与实现不变性检查均已完成。结构接触/远端扰动尚未运行。全部属于已查看数据上的开发工作。新结果入口为 `results/ecls_hard_controls_scored_v1/REPORT.md`。

当前投稿意向为优先争取 JCIM、采用非 OA 出版，见 `docs/SUBMISSION_STRATEGY.md`。

## 1. 评分冲突分解：完成

分析 6 个组件 / 72 条设计候选，将 ECLS 拆为 apo NLL − complex NLL。apo NLL 由既有 complex NLL 和 ECLS 重建；其代数协方差分解记录在结果 JSON 中。

- complex NLL 与 AF2 PAE 在 5/6 组件负相关；apo NLL 同样在 5/6 组件负相关。问题并非只在做差之后出现。
- 负 ECLS 按“越低越好”定向后，在 EXT002–EXT005 与 AF2 PAE 的相关为 −0.545 至 −0.685；EXT001 和 EXT006 接近零。
- 同一组件、同一生成方法内进行秩中心化后，原始 ECLS 与 PAE 标签的合并相关为 −0.104，接近零。该处理移除了组间秩均值差异；每组只有 3 条，不能证明生成方法是唯一原因，也不能视为因果调整。
- ProteinMPNN 来源候选平均 ECLS 为 0.153，平均 AF2 PAE/31 为 0.889；其他三类来源的平均 ECLS 为 −0.054 至 −0.028，平均 AF2 PAE/31 为 0.825–0.841。ECLS 偏好与 AF2 教师偏好在来源层面存在冲突。

结论：应优先检验生成来源效应和评价目标差异；现有结果不支持通过翻转 ECLS 方向来挽救筛选，也不支持把相关解释成真实结合优劣。

## 2. AF2 标签稳定性：完成

读取并核验 432 个已有 PAE 矩阵（72 候选 × 2 模型 × 3 seed），重算 H3→抗原方向性 PAE/31，逐项核对原标签均值。没有调用新的 AF2 推理。

|组件|单次预测 top3 与六次均值 top3 的平均重合率|两模型均值 top3 重合率|
|---|---:|---:|
|EXT001|66.7%|33.3%|
|EXT002|38.9%|33.3%|
|EXT003|100.0%|100.0%|
|EXT004|55.6%|33.3%|
|EXT005|94.4%|100.0%|
|EXT006|66.7%|33.3%|

重采样同时抽取模型与 seed，并保持所有候选配对；另报告留一 seed、候选 top3 入选频率、第 3/4 名间隔、六次方向一致的候选对准确率。只有 2×3 个计算重复，因此重采样区间是敏感性描述，不是校准过的统计置信区间。

结论：部分组件的硬 top3 标签确实不稳定。但 EXT003 和 EXT005 相对稳定，ECLS 在这两个组件的主终点召回率仍为 0；标签波动无法完整解释 ECLS 的失败。PAE/Ridge 的比较也应报告标签敏感性，而不能只依据单个汇总百分比。

## 3. 困难对照：设计与评分进展

执行结果：6 个组件中 4 个天然序列优势为正，组件等权均值 0.020089，描述性组件 bootstrap 95% 区间 [-0.008783, 0.048962]，跨零。三个显式种子结果一致；抗原序列置换没有改变评分。两个组件的单精度刚体不变性检查在位置 log probability 层面略超预设 1e-5 容差，原始失败保留，并另做双精度数值诊断。当前证据不足以推广为稳定的困难候选排序能力。

复现纠错：此前 ProteinMPNN CLI 的 seed=0 实际触发了随机选种子。新执行器绕过此行为，显式设置种子；旧缓存保留，并另存 `legacy_seed_audit.json` 比较全部既有候选的分数与排序。这一限制应与此前的 seed=0 记录一起阅读。

### A. 近天然序列对照（可优先执行）

每个组件准备 20 条 H3，共 120 条。通过交换两个不同氨基酸的位置产生对照，严格保持长度和组成，仅改变两个位置；以固定随机种子从所有唯一交换中抽取，完全不依据评分和 AF2 标签筛选。该对照比全面打乱更接近天然序列。

评分采用当前 ProteinMPNN 配置和 seeds 0、2281、20260916，分别计算 native ECLS − mean(control ECLS)。先对每组件汇总，再比较组件间效应与种子敏感性；不把 120 条相关对照当成 120 个独立样本。所有组件均报告，包含零差异和反向差异。没有真实结合标签，不能将这些对照称为已证实不结合的负样本。

### B. 实现负对照（先于结构解释）

当前 `conditional_probs_only_backbone=1` 的语义是 p(s_i | backbone)。因此，保持骨架不变的抗原序列置换，预期不改变 H3 条件概率；这是实现不变性检查，不能支持“识别了抗原序列”的结论。检查同 seed 条件下有效 H3 log probability 和 ECLS 的差值，预设绝对容差 1e-5；超限先检查解码顺序、坐标/链映射和数值实现，不筛掉失败组件。

对整个 complex 与 apo 同步施加刚体旋转/平移，预期也应保持评分。优先在内存坐标上实施，避免 PDB 三位小数写回造成额外扰动；若必须写回则单独量化舍入误差。

如果未来要评估抗原序列条件，必须另定义、实现并验证非 backbone-only 评分变体，并重做开发评估；它不能冒充当前冻结的 ECLS。

### C. 结构环境敏感性（已完成可行性审计）

基于设计骨架的 Cα 距离，预设接触区为抗原残基到 H3 最小距离 <8 Å，远端区为 >16 Å。这只是计算控制的操作定义，不是物理热点定义。

|组件|接触残基数|远端残基数|可配对残基上限|
|---|---:|---:|---:|
|EXT001|3|3|3|
|EXT002|8|1|1|
|EXT003|6|0|0|
|EXT004|2|0|0|
|EXT005|5|0|0|
|EXT006|4|0|0|

仅 EXT001/EXT002 可开展配对试验；不为凑足数量降低远端阈值。正式运行前需固定扰动生成器与几何质量阈值：接触/远端条件匹配残基数和骨架 RMSD，保持 H3/抗体骨架不变，并检验键长、键角、碰撞和链连续性。未通过几何质控的结果单列，不解释为特异性丢失。

主比较为扰动前后“天然相对近天然对照的 ECLS 优势”的变化。当前两组件只能做探索；若要声称可推广的接触依赖性，需要有足够远端区的新独立结构。对照扰动的物理生成器及几何质量阈值仍需在开发阶段确定，因此此项目前不是完整可执行的结构实验。
